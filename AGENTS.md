# Instruções do projeto

- O projeto é uma biblioteca Python publicada no PyPI.
- Não alterar a API pública sem explicar o impacto.
- Toda correção deve ter testes.
- Antes de concluir, executar `pytest`, o build do pacote e `twine check`.
- Não publicar nem criar versão automaticamente.
- Não alterar workflows de publicação sem revisar possíveis gatilhos duplicados.
- Usar type hints, logging e tratamento explícito de erros.
- Realizar mudanças pequenas e compatíveis com versões anteriores.
- Ao final, informar os arquivos alterados e os testes executados.
